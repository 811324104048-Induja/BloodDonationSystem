# Blood Donation Network & Emergency Matching Platform

A full-stack platform that connects blood donors with patients
requiring blood and prioritizes emergency requests.

## Technologies

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript

## Features

- Donor registration
- Patient blood requests
- Emergency matching
- AI-assisted donor ranking
- Secure authentication
- Role-based access control
